# 素章 · 法律方法论 SOP（独立版）

两份可直接执行的办案规程，**零代码、零数据库、零服务端**。插件里没有 MCP 服务、没有启动脚本、没有依赖安装步骤：只有 `plugin.json` 和两个 `SKILL.md`，复制到任意支持 Agent Skills 的客户端即可使用。

## 里面有什么

| Skill | 解决的问题 | 产出 |
|---|---|---|
| `legal-table-script-sop` | 非标银行流水、多表头对账单、跨页台账无法用通用列映射处理 | 可复核的 Python 算账脚本 + 汇总表 + `skipped_rows` 异常跳行清单 |
| `legal-chart-substantive-review` | 对外关系图 / 诉请金额图在客户沟通、当庭呈递前的法律实质复核 | 《复核问题清单》，交承办人终审 |

两份 Skill 都不假设你用了哪个软件：输入可以是本地目录里的 Excel/CSV，也可以是 Obsidian 笔记里的摘录，或律师自己维护的台账。它们只规定"怎么算、怎么核、怎么留痕"。

## 三条共同纪律

1. **先看样本再动手。** 只读前 20 行确认列名、编码、日期格式、币种与借贷方向表示，不把整表塞给模型肉眼累加。
2. **计算必须是确定性的。** 用 Python 与 `decimal.Decimal`（`ROUND_HALF_UP`）算钱，禁止浮点，禁止"模型心算"。解析不了的行单独列出，绝不静默当 0 或丢弃。
3. **结论交人。** 脚本、汇总、复核清单都是给承办人复核的材料；任何数字或判断在被人工确认前都不是定稿。

## 数据边界（必读）

- **涉密、涉个人隐私或当事人禁止上云的案卷，严禁接入云端模型。** 这类案件只能用本机离线模型，或干脆只用脚本、不经过任何模型。
- 本插件不会上传、不会联网、不会写数据库；数据流向完全由你使用的客户端与模型决定。第一次处理真实案卷前，先确认客户端的隐私设置与所用模型是否合规。
- 生成的脚本与汇总属于工作底稿，按所内档案要求存放，不要放进同步盘或公共仓库。

## 与素章工作台的关系

两者**可以完全独立使用**：没装素章，这两份 Skill 照样完整可用，输出照旧是脚本、汇总表和问题清单文件。

若你已经装了素章（PlainFolio）本地离线案件工作台，可在各 Skill 文末「可选：若已接入素章工作台」一节找到把结果写入待确认提案的做法。那一步是可选的，且必须遵守素章的授权门禁：默认 `deny_all`，须承办人在本机按案授权后才可读写，写入一律进入待确认区由人确认。

## 安装

- **便携客户端**：把本目录整个复制（或软链）到客户端的 skills / plugins 目录，使其能看到 `plugin.json`。
- **Codex 等支持插件市场的客户端**：在本仓库根目录执行 `codex plugin marketplace add .agents/plugins/marketplace.json`，然后安装 `plainfolio-legal-sops`。
- **只想用单份 Skill**：把对应的 `skills/<名字>/SKILL.md` 单独复制到客户端的 skills 目录即可，不需要其余文件。
