# 非标表格外部脚本解析规程（SOP）

适用条件：目标表格无法直接通过工作台通用「列映射出边」（如存在多行合并表头、动态借贷符号列、多币种混列、多表关联对账、嵌套摘要拆解等非标结构）。

## 授权前置与硬围栏纪律（必须先执行）

1. **禁止默认连接、探测或列举工作台**。即使对话里提到案卷，在用户明确授权前也不得调用 `list_cases`、`list-cases`、`search_case` 或任何带 `case_id` 的工具与命令。工作台默认 `deny_all`（全局锁死），未获授权时除 `list_cases(limit=0)` 连通探活外一律返回 `forbidden`。
2. **先向用户申请明确授权**，一次问清三件事：
   - 本次允许访问的**具体目标案件**（`case_id` 或案件名称）；
   - 当前所连接的对话模型**是否合规**接触该案材料——涉密、涉个人隐私或当事人禁止上云的案卷，**严禁**接入云端模型，只能用本机离线模型；
   - 请用户**本人在本机终端**执行 `scripts/lwb agent-grant <case_id>`（Windows 为 `scripts\lwb.cmd agent-grant <case_id>`；桌面安装包用 `<可执行文件> --run-cli agent-grant <case_id>`）临时放行该单案。授权只能由承办人本人执行，你不得代跑，也不得要求用户把命令交给你来执行。
3. **禁止绕过硬围栏**。若工具返回 `forbidden`（未获授权或处于 `deny_all`），立即停止该案的全部操作并如实告知用户「需由您在本机授权」。**严禁**改用 Shell / Python 直连数据库、读取 `var/data`、读取 `.env`、改写 `var/runtime/agent-access.json`，或改走 CLI / HTTP / 另一个客户端绕过门禁；这些做法一律视为越权。
4. **用完即锁**。任务结束回复用户时，提醒用户按需执行 `scripts/lwb agent-revoke <case_id>`（Windows 为 `scripts\lwb.cmd agent-revoke <case_id>`）收回该案权限，或执行 `scripts/lwb agent-lock` 全局锁死、收回全部权限。不要替用户判断「下次还要用，先留着」。

## 执行步骤

1. **先读样本，严禁盲猜或肉眼全表手算**：
   - 仅读取表格前 20 行样本与工作表清单（可调用表格预览接口或用 Python `openpyxl`/`csv` 只读检查前 20 行），确认列名、编码（UTF-8 / GB18030）、日期格式、币种、借贷方向表示及异常空行形态。
   - **严禁**把几百行原始流水直接塞进模型上下文让大模型肉眼累加。

2. **编写透明、确定性的本地 Python 聚合脚本**：
   - 使用 `decimal.Decimal`（`ROUND_HALF_UP`）换算整数分，严禁使用浮点加减乘除。
   - 显式处理方向翻转（收入/支出、借/贷、正/负号），对无法解析金额、日期或主体缺失的异常行单独输出 `skipped_rows`（含 1-based 行号与原始行内容），绝不静默丢弃或当成 `0`。
   - 在隔离工作目录或临时分析脚本中运行全量计算，输出：
     - 汇总结果表（按主体对或明细汇总，含总金额分、笔数、起止日期、原始行号范围）；
     - 跳行异常清单；
     - 可复核的脚本文本（注释清晰、无外部隐藏状态）。

3. **结果留痕与工作台待确认写入**：
   - 使用 `save-analysis`（`statement_kind="agent_analysis"`）将**聚合脚本正文、汇总表与异常跳行清单**保存为本案工作分析留痕，并绑定源材料/片段 `source_ref`（若源材料尚未解析，先等待或注明源 `material_id`）。
   - 按 `graph` / `claims` 的幂等写入命令（携带唯一 `--request-key`）写入待确认提案：
     - 关系图新增主体/关系默认进入 `pending_changes`（`credibility` 须先以 `suspected` 等状态建边并附原表格 `material_id` 出处及行号范围说明，不得绕过人类确认直接标为已定稿）；
     - 诉请金额新增/修改同样进入待确认区，不计入小计与总计。

4. **人工复核收口**：
   - 向承办人汇报汇总表、异常跳行清单与待确认提案编号，提示承办人在网页工作台对照原表核验后逐条确认或撤回。
