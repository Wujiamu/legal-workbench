# 案件期限与证据标注

状态：2026-11-14 实现。适用范围与验收见 [诉讼工作台 UI 重构](../changes/20261114-诉讼工作台UI重构.md)。

- **办案进度由承办人登记。** 曾考虑把案内页签作为办理进度，或者从材料和处理任务推断进度。首版采用独立的案件字段。承办人可自由返回材料、检索、分析或标注工作区，首页根据显式登记的日历日期排序。期限是案件内的有序列表，使用案件 revision 一次保存。未来需要跨案任务操作、期限提醒或单条期限独立写入时，再评估独立表。
- **沿用固定文件版本和历史来源引用。** 曾考虑将 OCR 文本或外部 Markdown 作为单独导入物。当前检索沿用工作台的解析与索引。PDF 来源用对应版本渲染具体页，图像来源使用解析定位的帧。取得方式保存在材料记录，显示的是当前登记信息。历史片段的原文、版本和位置仍取原来的解析记录。
- **标注独立存储。** 将标注保存为分析成果可复用审核状态，但缺少与文件版本、具体页和标注性质的直接关系。标注可按案件检索。Agent 原文保存后固定，人工确认或修订单独记录。网页承担人工复核，MCP 提供 Agent 登记及检索。新识别结果提交为独立的待复核记录，已有复核保留。
- **数据库升级。** 0004 增加可空字段、空期限默认值及标注表。旧案件和材料可补录。回退时直接降级会丢失新增数据，应使用升级前的数据库和受管目录备份恢复。
