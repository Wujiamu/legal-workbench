# 横向可视化与二三期图表演进路线

## 一、全局可视化版图定位

工作台的图形化按“精而非泛”收敛为四个层次，一期（见 [20261122-图表程序化能力与对外引用导出](20261122-图表程序化能力与对外引用导出.md)）已涵盖零迁移底座与主体关系图 P1 四项；本文档记录**二期（P2）与三期（P3）的横向大图与主体关系图进阶项**：

- **已有图形（`0008_claim_amounts` 已上线）**：跨案期限时间轴、办案程序进度图、案件主体关系图（首版）、诉请金额瀑布图（`WaterfallChart`）。
- **一期施工中/待实施（零迁移）**：一源三态导出与复核审计包、关系图共现秒查与阅卷一键入图、防漏与强指纹审计面板、案卷健康与引用覆盖格子图、候选主体消歧台、通用表格列映射出边、外部复核 Skill。
- **下方为二期（P2）与三期（P3）规划池**，建议在真实案件试用已有功能后，按实际痛点逐项挑出单独立项。

## 二、第二优先级（P2 · 核心横向大图、客户展示与进阶能力）

多需新增可写数据模型，或依赖真实案卷试用后的交互反馈触发。

### 2.1 横向核心可视化大图（补齐“事、钱、攻防、原件”）

| 编号 | 事项 | 呈现形态 | 核心价值 | 需新迁移 | 触发条件 / 复用点 |
|---|---|---|---|---|---|
| **P2-H1** | **多轨案件事实时间线** | 多泳道横向时间轴（合同轨 / 资金轨 / 沟通催告轨 / 程序轨） | 厘清复杂案情因果先后、履约断档、违约节点与诉讼时效中断；兼具自用与客户/法庭展示价值 | 是（案件事实事件表） | 复用 `exact_values(date)`、`case_entities` 与 `source_ref`；落地后顺带支撑主体关系图按时间切片 |
| **P2-H2** | **资金流向专项图** | 桑基图（Sankey）或按金额线宽编码的有向流图 | 专攻借贷、投资回购、抽逃出资、过桥走账与环状回流；3 秒看清资金净流向 | 否（复用 `case_entities` 与 `fund_flow` 边） | 关系图专项视图；在 Wave 2B 通用表格流水导入就绪后价值倍增 |
| **P2-H3** | **证据—待证事实二维覆盖矩阵** | **二维棋盘/热力矩阵**（纵轴证据组，横轴待证事实/要件；格内标直接/间接/孤证/被反驳） | 视觉一眼暴露“整列空白 = 举证致命缺口”“单格孤证 = 庭审易爆点”，不可替代的庭前兵器 | 是（待证事实与证据映射表） | 复用 `evidence_items` 与 `source_refs`；坚决不做成节点连线图 |
| **P2-H4** | **争点—要件攻防树** | 树形结构图（诉讼请求 → 法定要件 → 争议焦点 → 双方攻防点与强度标色） | 请求权基础分析法可视化，一眼看出最短胜诉路径与我方薄弱要件 | 是（争点节点表或扩展通用树） | 复用办案进度树形组件、证据目录与 `claims` 诉请项 |
| **P2-H5** | **原件图像区域框选标注** | PDF 页 / 聊天长截图 / 现场照片上的矩形框选与编号钉点 | 把现有“页级标注”精准化到具体条款、印章或金额行；支持导出带框证据摘录图 | 是（扩展 `annotations` 坐标字段） | 复用 PDFium 预览与 `annotations` 人工复核流 |
| **P2-H6** | **风险敞口与策略情景区间图** | 极简情景区间条（保守 / 基准 / 乐观回款或赔付区间，叠加诉讼成本）＋简易程序分支图 | 直接回应客户“打下去 vs 调解划不划算”的商业决策诉求 | 轻量扩展（挂 `claims` 或独立情景表） | 直接复用 `claims` 分组汇总数据 |
| **P2-H7** | **多版本文书视觉 Diff** | 双栏红绿高亮对照（面向同一材料的多个 `file_versions` / 工作副本） | 快速核对对方回传合同或改稿版本的字句变动 | 否（只读对比文本层） | 复用 `file_versions` 与已解析 `segments` |
| **P2-H8** | **工时分布与期限负荷图** | 按案件/阶段的条形图 ＋ 期限月历热力格子（首页/工时页） | 复盘耗时分布、预警单周开庭与举证扎堆 | 否（纯只读投影） | 复用 `time_entries` 与 `cases.deadlines` |

### 2.2 主体关系图进阶能力（纵向二期）

| 编号 | 事项 | 呈现与机制 | 核心价值 | 触发条件 |
|---|---|---|---|---|
| **P2-G1** | **GIS 风格同坐标多图层透明叠放** | 锁死全部主体节点坐标不变，按来源/主题拆成可勾选透明图层（工商股权底图 / 合同契约层 / 资金流向层 / 强指纹暗线层 / 诉辩主张层）逐层叠放 | **对客户汇报与法庭演示极具表现力**：通过同坐标逐层叠加，让“签约方 A-B 与收款方 A-C 错位”瞬间跃然纸上 | 主体关系图真实试用并出现高频对外汇报场景时立项 |
| **P2-G2** | **按材料/证据反查受影响边（质证压力测试）** | 选中某份证据/材料，高亮图中所有**唯一依赖它支撑**的关系边；未来接入质证采信状态后支持推翻级联标警 | 庭前压力测试：“若证据 2-3 被推翻，哪几条关系链会立刻悬空” | 轻量反查随时可做；完整质证状态级联待 P2-H3 同步 |
| **P2-G3** | **图论“结构洞”庭前体检** | 手动触发的确定性拓扑体检：标出“有大额资金边无合同/借贷边”“有合同边无履约/资金边”“有担保边无决议出处”等缺失提示 | 帮承办人发现隐蔽代理线索与补证方向，零黑盒 | 仅作中后期手动“庭前体检”按钮，避免前期半成品图满屏误报 |
| **P2-G4** | **事实表格视图与画布双向编辑** | 为主体与关系提供紧凑表格编辑页签，与 React Flow 画布共享同一套写命令 | 批量录入/核对几十条关系、金额与出处时比逐一拖拽更快 | 真实案卷试用后若画布批量录边体感偏慢再补 |
| **P2-G5** | **高频案由静态空白骨架模板 + 来源细分** | 按真实高频案由（如建工转分包、民间借贷担保、股权代持）提供 2–3 套静态占位骨架一键套用；并将变更来源细分为 `human / program / agent` | 降低同类大案冷启动成本，一眼区分程序硬提取与 AI 语义建议 | 积累真实案件使用频率后按需沉淀 |

## 三、第三优先级（P3 · 远期可选保留，高工程量或持续维护换专项增强）

以下项目因工程量较大、持续维护成本偏高或仅适用于特定案型而排在远期，但具备明确场景价值，予以保留备选：

| 编号 | 事项 | 定位与保留理由 | 启动前提 |
|---|---|---|---|
| **P3-1** | **可视化提取步骤画布（节点流水线视图）** | 当用户希望直观展示或交互式检视“扫卷范围 → 实体候选 → 别名消歧 → 共现/指纹 → 入图”全链路过程时，将一期固定分步确认台升级为可视节点流程画布 | 一期分步确认台跑通后，确有复杂流程直观展示或节点级定制诉求时启动 |
| **P3-2** | **高频固定外部格式专项解析适配器** | 针对最高频的主力银行流水导出、国家企业信用信息公示报告或主流商查导出，做成独立可插拔适配器，实现零手工列映射的一键解析 | 当 Wave 2B 通用列映射在某几类高频固定格式上显得繁琐、值得承担格式变动维护成本时按需按个添加 |
| **P3-3** | **确定性算术型图计算（股权穿透持股比例）** | 基于已确认的 `equity_control` 有向边与 `share_pct` 属性，用确定性图算法计算多层间接持股比例与控制路径 | 仅限纯数学/图论算术计算，严禁越界输出法律定性结论 |
| **P3-4** | **标的物 / 权利流转链视图** | 围绕特定房产、批次货物、票据背书或知产侵权产销链展示“物/权”在多主体间的流转路径 | 实际承办此类高频物权/票据/产销链案件时按需立项 |
| **P3-5** | **单条结论来源血缘链路按需展开** | 在多版本反复重解析或深度质证核查时，展开单条结论的横向血缘路径（分析/边 → 片段 → 文件版本 ← 原件哈希） | 日常沿用 `SourcePreview`，仅在多版本交叉转引成为真实痛点时补充 |
| **P3-6** | **专利 / 知产专项图文比对矩阵** | 独立权利要求技术特征 × 涉案产品/现有技术比对表（配合附图局部高亮对照）与专利审查/无效时间线 | 工作台正式拓展至专利 FTO / 无效 / 侵权业务阶段时单独立项 |
