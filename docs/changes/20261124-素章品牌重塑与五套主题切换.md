# 素章 · PlainFolio 品牌重塑与五套主题切换变更单

状态：已封板（已应用至 `0009_case_metadata` + 2026-11-24 素章品牌重塑与五套实时主题切换）

## 1. 变更背景与定位

原工作台沿用「法律工作台 / Legal Workbench」名称与森林绿＋黄铜天平视觉，在外观和辨识度上与市面上通用法律 SaaS 雷同。本轮完成品牌升级与主题系统重构：

- **新品牌名**：**素章 · PlainFolio**（「素」指未经篡改的本色原件底本，「章」指梳理成型的案件篇章结构、目录与落章核验）。
- **兼容边界**：桌面双击启动器文件名 `法律工作台.app` / `法律工作台.bat`、底层 CLI `scripts/lwb` 及 `scripts/lwb-launch` 报错弹窗标题保持兼容不改名，避免破坏既有脚本、Windows 验收清单与 `test_windows_compat.py` 断言；同时同步替换全部应用图标与网页/文档品牌展示。
- **新 Logo（图形 C · 编简成章）**：圆角方底内三列高矮错落的素白简册，由一道横贯封签与三枚穿绳孔编联成“章”，彻底去除天平与法槌元素；网页端 `<BrandMark />` 绑定 CSS 变量，随主题切换实时联动。
